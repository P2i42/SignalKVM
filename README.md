# SignalKVM

本地运行的 Windows 托盘 / macOS 菜单栏小应用。它监听本机键鼠活动，并在需要时通过 DDC/CI 把显示器切换到这台电脑连接的输入源。Windows 版支持自动发现多台 DDC/CI 显示器并按显示器保存端口映射。

不使用局域网、云服务或两台电脑之间的通信。

## 使用

1. 在每台电脑上运行 SignalKVM。
2. 打开设置后扫描显示器，选择目标显示器。
3. 选择这台电脑和另一台电脑实际连接的输入源；每台显示器的配置会独立保存。
4. 按需要设置切换灵敏度、光标门控、停留时间和一键切换快捷键。
5. 打开“开机后自动启动并驻留后台”。
6. 关闭设置窗口后，应用会继续在托盘或菜单栏运行。

## Windows 功能

- 自动检测本机键鼠活动并切回本机输入。
- 自动枚举显示器，读取型号、厂商、序列号和 Hardware ID。
- 通过显示器 DDC 能力字符串扫描可用输入源。
- 按显示器分别保存本机端口、另一台电脑端口和输入源列表。
- 使用显示器实例 UID 精确匹配，同型号多显示器不会串控制。
- 高 / 标准 / 稳健三档切换灵敏度。
- 光标门控：光标在指定显示器内持续活动达到设定时间后自动切回，不要求鼠标静止；其他显示器上的键鼠活动不会触发。
- 窗口位置检测：窗口新开、恢复或移动到目标显示器时也会触发切换。
- 防止重复写入同一个目标输入源，进入目标显示器后不会反复黑屏切换。
- 自动把 DDC 显示器映射到桌面屏幕编号；四屏环境下可直接选择从左到右第几块屏幕。
- 设置空闲多少秒后，新的键鼠活动才允许触发切换。
- “一键切换本机 / 另一台电脑”按钮，根据当前输入自动双向切换。
- 可配置全局快捷键，默认 `Control+Alt+PageDown`；支持按键录制和冲突检测。

Windows 便携版直接运行 `SignalKVM.exe`。macOS Apple Silicon 版首次打开时，请右键 `SignalKVM.app`，选择“打开”。建议把应用移入“应用程序”目录后再启用开机启动。

```powershell
npm run package:win
npm run package:mac
```
